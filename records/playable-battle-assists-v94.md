# v94 전투 보조와 오프닝·효과음

## 게임 안에서 설정하기

타이틀에서 **OPTIONS → 전투 보조**를 연다. 처음 실행하거나 기존 저장 파일을 불러오면 두 보조 모두 꺼져 있다.

| 항목 | 조작과 적용 범위 |
| --- | --- |
| D-스피릿 | 1인 일반전에서 내 D-스피릿을 0~999 중 선택한 숫자로 고정한다. 좌우로 1씩, L·R로 100씩 바꾼다. 0에서 왼쪽을 누르면 고정을 끈다. |
| 보스 체력 1 | 켜면 7·11단계 보스의 체력을 전투당 한 번 1로 맞춘다. 보스가 쓰러지려면 플레이어의 공격이 적중해야 한다. |
| 저장·돌아가기 | 위아래로 항목을 고른다. **저장**에서 A를 누르면 다음 실행에도 설정이 남는다. **돌아가기** 또는 B로 변경을 취소한다. |

게임의 기존 저장 영역 바로 다음에 있는 EEPROM 34번 블록에 두 값을 함께 쓴다. 기존 저장 파일, 잘못된 숫자, 손상된 블록과 읽기 실패는 모두 보조 꺼짐으로 처리한다. 저장 오류가 나면 메뉴에서 다시 시도할 수 있다. 1인 대전은 장면을 만들 때 설정을 한 번 읽고, 점수 표시와 결과 판정이 참조하는 실제 전투 데이터를 갱신한다. 두 보스는 상대 캐릭터와 연결된 보스 동작 데이터까지 확인한 뒤 적용한다.

## 원작과 대조한 화면과 소리

네 번째 오프닝에서 두 캐릭터가 참조하는 그림 목록의 시작을 원본과 같은 위치로 고쳤다. 창 없는 실제 재생에서 같은 자세를 골라 비교한 결과 왼쪽 1,307픽셀, 오른쪽 1,326픽셀의 모양과 색이 원본과 일치했다. 시작 버튼을 누른 뒤 타이틀이 뜰 때까지 원더스완은 101프레임(1.33825초), GBA는 80프레임(1.33942초)이 걸렸다. 수정 전 GBA는 42프레임(0.70319초)이었다. [오프닝 비교 기록](opening-fourth-pair-and-skip.md).

추가 캐릭터 효과음 다섯 가지를 원더스완 드라이버로 직접 재생해 GBA 출력과 비교했다. 네 가지는 원본의 파형과 좌우 균형을 복원했고, 기존에 잡음처럼 들리던 C6는 GBA 웨이브 채널로 열 개의 고음을 연주한다. C6가 끝난 뒤 같은 채널에서 배경음악이 이어지는 것을 확인했다. GBA의 음높이 간격과 배음에는 두 기종의 차이가 남는다. [효과음별 음높이·파형 및 배경음악 대조](added-fighter-original-timbre-v94-20261124.md). 로컬 비교 녹음 `build/v94-release/five-sounds-wsc-gba.wav`에서는 효과음마다 원더스완, GBA 순서로 들을 수 있다.

## 옵션 검증

네 언어에서 게임 안의 **저장**으로 999와 보스 보조 켜짐을 기록한 뒤 다시 켜서 읽었다. 통합 검수판에서도 한국어 999·보스 켜짐, 영어 0·보스 꺼짐이 재시작 후 유지됐다. 이전 판의 세이브로 400회 관찰하는 동안 보조는 점수를 쓰지 않았다. 0으로 고정한 별도 일반전에서는 점수가 처음 변했을 때 다시 0이 되었으며, 4,987회 연속 관찰에서 0을 읽었다. 독립 검사기에서 숫자와 보스 설정 조합 2,002개 및 손상·저장 오류의 처리를 확인했다. [네 언어 옵션과 기존 세이브 검증](battle-assist-options-20261124.md).

## 어려움 난이도 캠페인

`EF8BBC67`을 게임 내 옵션에서 만든 실제 저장 파일로 켠 뒤 일반 컨트롤러로 어려움을 선택했다. 일반전의 D-스피릿 관찰 72,010회에서 999가 유지됐고, 전투 중 점수가 달라진 27회에 게임이 직접 고정값을 적용했다. 7단계와 11단계 보스는 체력이 각각 한 번 1로 설정된 뒤 87,304프레임과 92,026프레임에 플레이어의 공격으로 쓰러졌다. 엔딩을 거쳐 97,741프레임에 타이틀로 돌아왔으며, 캠페인 저장 후에도 보조 설정 8바이트가 그대로였다. 그 엔딩 저장 파일로 게임을 완전히 껐다 켜 다시 시작한 일반전에서 999가 적용됐고 400회 연속 관찰에서도 유지됐다. 컨티뉴, 에뮬레이터 치트, 메모리 쓰기, 중간 상태 불러오기는 사용하지 않았다.

게임 진행 기록은 `build/v94-final-assist-campaign/play.txt`에 있다(SHA-256 `2E86646913B2EED4117E57504AE998739E5B21C8EC454B910C4C6EE03FC6870A`). 이 실행의 컨트롤러 스크립트는 커밋 `c2ef733`의 `tools/bizhawk_native_play_assists.lua`다. 당시 실행기는 종료 시점의 파일 해시를 기록해 요약 JSON에는 진행 중 보강된 단기 검사용 스크립트의 해시가 들어갔다. 현재 실행기는 시작할 때 복사본을 만들어 그 파일을 사용하고 해시를 기록한다.

## 원본에서 두 번 빌드한 결과

미국판 GBA와 원더스완 원본에서 시작해 두 작업 폴더에서 독립적으로 빌드했다. 앞선 판의 579개 파일은 보관 중인 v93 결과와 일치했다. 두 폴더에서 각각 옵션, 전투 처리, 오프닝, 효과음을 적용한 결과는 상대 경로와 내용 모두 591개 파일이 일치했다. 두 최종 롬과 배포 폴더의 GBA가 동일하다. `build/v94-repro-20261124/report.json`의 SHA-256은 `02EAAF87A9DCF09B08C4A3F05BFD0EE816F64542A46E66D09DEB89CD10E09392`다.

정식 빌드 진입점은 `tools/build_current_candidate.py`다. 원본 롬 세 개와 기존 글꼴·라이선스 인수를 사용한다. 효과음 녹음 폴더를 지정하지 않으면 입력 원더스완 원본을 창 없이 실행해 다섯 효과음을 직접 추출한다. 미리 추출한 녹음을 쓸 때는 `--fighter-sfx-renders`로 지정할 수 있다. 두 방법에서 최종 게임 파일이 일치했다.
