# 캠페인 마스터 태그 축하 화면

원더스완판은 마스터 태그를 받으면 색종이 30개의 시작 위치를 정하고, 화면에 그리기 전에 움직임을 한 번 계산한다. 기존 GBA판은 색종이마다 임의의 초기 속도를 넣었다. 속도의 상한도 원더스완판은 7, 기존 GBA판은 9였다. 캠페인 엔딩이 색종이를 시작하는 한 곳만 바꿔 원본 계산을 연결했다. 이름을 입력하는 동안에도 같은 색종이가 이어진다.

수정 전 ROM은 `2922F586`, 수정 후 ROM은 `6AE6D4AF`다. 기존 장면이 사용하던 메모리 3,040바이트 가운데 304바이트를 색종이와 애니메이션 시간에 쓴다. 두 ROM을 비교해 새 코드와 캠페인의 호출 한 곳 이외의 바이트가 같은지 확인했다.

같은 난수를 주고 원본 계산과 GBA 실행을 180프레임 대조했다. 색종이 좌표 5,400개, 화면 안에 들어온 타일 2,563개, 난수 호출 2,308회가 일치했다. 화면 아래에서 다시 나타나는 경계 사례도 네 번 확인했다. 검증 기록은 `build/mode11-source-particles-20261124/independent.json`이며 SHA-256은 `5B9BCCB16836300552347D9768652A44C71443ED6B45E70F12E039CDB155E06E`다.

창 없는 실행에서는 앞서 보조를 사용한 캠페인의 체크포인트에서 시작했다. 2,310점으로 마스터 태그를 받고 BCD를 입력한 뒤 타이틀로 돌아왔다. 새로 게임을 켜 컬렉션에서 BCD를 다시 읽고 B 버튼으로 나왔다. 축하 화면과 이름 확인 화면에서 새 색종이 코드가 실제로 쓰이는 것도 확인했다. 실행 기록은 `build/mode11-source-particles-20261124/actual.json`이며 SHA-256은 `3C11625C2A45DCA343EB92D6BC4C83B94C1FFA3CC6B6D93701A20DF693EB471B`다.
