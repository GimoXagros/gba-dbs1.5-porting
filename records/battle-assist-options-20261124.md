# 전투 보조 설정

옵션 목록에서 언어 다음에 있는 **전투 보조**를 선택하면 설정 화면이 열린다. 아래로 한 번 더 움직이면 기존의 돌아가기 항목을 선택할 수 있다. 영어·일본어·한국어·디지코드 모두 같은 순서로 조작한다.

- **D-스피릿**은 끄거나 0부터 999까지 고정할 수 있다. 십자키 좌우로 1씩, L과 R로 100씩 조절한다. 꺼짐에서 오른쪽을 한 번 누르면 숫자 0이 표시된다.
- **보스 체력 1**은 좌우로 끄거나 켠다. A로도 전환할 수 있다.
- **저장**은 두 설정을 함께 기록하고 옵션 목록으로 돌아간다. **돌아가기**와 B는 편집한 값을 버린다.

기본값은 두 항목 모두 꺼짐이다. EEPROM 블록 34의 처음 네 바이트는 `BAS1`이다. 다음 두 바이트에는 리틀엔디언 설정값, 마지막 두 바이트에는 그 값의 1의 보수를 기록한다. 하위 10비트의 0은 꺼짐, 1~1000은 숫자 0~999다. 비트 10은 보스 체력 설정이다. 여덟 바이트의 형식이나 수치 범위가 잘못되거나 장치를 읽지 못하면 두 설정을 끈다. 열기와 취소는 EEPROM에 쓰지 않는다. 블록 0~33에 있는 기존 세이브·Shoot·해금·전적은 별도로 보존한다.

설정 읽기 함수는 ARM `08DCC204`, 쓰기 함수는 `08DCC274`다. 두 함수 모두 r1~r12와 LR을 보존한다. 옵션 페이지는 기존 우선순위 1500 태스크 페이로드의 마지막 여덟 바이트를 쓴다. 화면을 스크롤할 때 원본 렌더러가 r6/r7을 바꾸므로 호출 전후로 보존해야 원래 스프라이트 좌표를 복구할 수 있다.

## 빌드와 검증

| 항목 | SHA-256 |
| --- | --- |
| 입력 v93 | `D432DBE9B221A0EFC15B644B8E76A0D39D374DFF1087165A917EF977A3E8BD99` |
| 옵션 적용 ROM | `C95C8B85C5FCC882E2BD14E8BB5A453F606D6C8560B4D8311D0AFD37489DF7A3` |
| 옵션 적용 기록 | `5413E876EFEB74F9B2CD4F798AD6E2A9D5380B98386D8370119A4788ED505055` |
| 독립 검증 결과 | `BD5A96B42E594E7FE7FE60556449B85C3B3CB7166E422DADB44B07E6687BB67C` |

독립 검사기는 최종 바이트에서 변경 구간을 모두 되돌려 입력 ROM을 복원했다. 실제 ARM 명령으로 설정 조합 2,002개를 쓰고 다시 읽었다. 구형 세이브의 초기 패턴 2종, 한 비트씩 손상시킨 64건, 범위 밖 설정, 읽기·쓰기 오류도 검사했다. 장치 오류는 블록 인터페이스에서 모사했다. 보조 화면의 최대 스프라이트 수는 영어·일본어·한국어·디지코드 순서대로 80, 80, 79, 81개였다.

각 언어에서 새 게임을 시작해 일반 컨트롤러로 HARD를 선택한 뒤 999와 보스 체력 1을 저장했다. 언어별로 에뮬레이터를 종료하고 별도 프로세스에서 실제 저장 파일로 다시 켰을 때 보조 설정이 그대로였고, 다시 읽는 동안 설정 쓰기는 없었다. 원작의 난이도는 재시작 시 보통으로 돌아가므로 HARD 캠페인을 새로 시작할 때 옵션에서 다시 선택한다. 실행 화면과 기록은 `build/battle-assist-live-b-l0`부터 `l3`까지의 `clean`과 `cold`에 있다. 제공된 세이브와 게스트 메모리 쓰기는 사용하지 않았다.

통합 ROM `EF8BBC67DB243A8CCAFA25744EFB371CC097C323F45D25060419B33B577B75BA`에서도 한국어 999·보스 켜짐과 영어 0·보스 꺼짐을 각각 일반 조작으로 저장했다. 영어 0의 실제 EEPROM SHA-256은 `47D3633F6385E228FD3A09EA8B25CA2DCF94DE1A7C168B756A2CE24EDDBA0676`, 한국어 999는 `135E7C1EB60BD9F1B9EA3C4895C008D3301CE98E2AB5180F86662661BD7B1BB3`이다.
