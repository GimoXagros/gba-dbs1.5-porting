`savestate.save` and `savestate.load` are prohibited while input/memory callbacks execute. The observer must latch the source event in its execute hook, then save synchronously from the outer Lua path after `frameadvance` returns. Therefore the source-hook frame/instruction and the later checkpoint frame are separate observations. Native `System::Advance` runs graphics lines and flushes sound; managed `WonderSwan.FrameAdvance` increments `Frame` after that native call returns. An outer checkpoint must not be described as an instruction-exact hook checkpoint. [SaveStateLuaLibrary](https://github.com/TASEmulators/BizHawk/blob/bdddf4a58aa1a022afb11dc73294a81a5aa7bbd5/src/BizHawk.Client.Common/lua/CommonLibs/SaveStateLuaLibrary.cs), [WonderSwan.FrameAdvance](https://github.com/TASEmulators/BizHawk/blob/bdddf4a58aa1a022afb11dc73294a81a5aa7bbd5/src/BizHawk.Emulation.Cores/Consoles/WonderSwan/WonderSwan.cs), [native Advance](https://github.com/TASEmulators/BizHawk/blob/bdddf4a58aa1a022afb11dc73294a81a5aa7bbd5/wonderswan/system.cpp).

The Lua save API returns a boolean, but the API layer suppresses a special API-only exception and a tool controlling savestates may handle the call without writing the requested file. A trustworthy capture checks the returned value, a fresh output path, a newly created nonempty file and its actual supported container/core payload. Load requires an existing file, reports failure as false, validates version/sync settings and can be redirected by a controlling tool. `suppressOSD=true` suppresses screen messaging, not errors or provenance checks. [SaveStateApi](https://github.com/TASEmulators/BizHawk/blob/bdddf4a58aa1a022afb11dc73294a81a5aa7bbd5/src/BizHawk.Client.Common/Api/Classes/SaveStateApi.cs), [MainForm state path](https://github.com/TASEmulators/BizHawk/blob/bdddf4a58aa1a022afb11dc73294a81a5aa7bbd5/src/BizHawk.Client.EmuHawk/MainForm.cs).

The full native state serializes graphics, memory, EEPROM, RTC, sound, CPU, interrupts, rotate and prior buttons. The managed core adds lag status/count and frame. The ZIP container also supports sync settings, optional framebuffer, movie data and UserData. Loading UserData replaces the user bag; continuation must explicitly restore/check the new output and run arguments after loading. Lua closures, hooks, observer counters, HP1 one-shot lifetime and policy-local UI/chase state are not serialized. A dedicated resume phase or exact captured input replay is required; restarting the old approval-bearing driver is not equivalent continuation. [SavestateFile](https://github.com/TASEmulators/BizHawk/blob/bdddf4a58aa1a022afb11dc73294a81a5aa7bbd5/src/BizHawk.Client.Common/savestates/SavestateFile.cs), [native state components](https://github.com/TASEmulators/BizHawk/blob/bdddf4a58aa1a022afb11dc73294a81a5aa7bbd5/wonderswan/system.cpp), [managed native wrapper](https://github.com/TASEmulators/BizHawk/blob/bdddf4a58aa1a022afb11dc73294a81a5aa7bbd5/src/BizHawk.Emulation.Cores/Consoles/WonderSwan/WonderSwan.IStatable.cs).

For a binary state, the genuine ZIP normally contains `BizState 1.0`, `BizVersion.txt`, `Core.bin.zst` and `SyncSettings.json` (the text-core format is a distinct supported configuration). After decompressing the core entry, its first int32 is the native payload length; its suffix is one bool plus two little-endian int32 values for lag/count/frame. Exact primitive-field serialization puts native RAM at offset2382/length65536, SRAM length at67918 and SRAM bytes at67922; this ROM requires32768. These offsets are within the native payload, excluding the initial4-byte managed length. They allow checkpoint RAM/SRAM/frame equality checks against separately captured boundary dumps. That equality alone is not full continuation equivalence: the exact remaining CPU/peripheral state, core/exe/ROM/sync-settings pins, controller input timing and replay policy still matter. [ZIP writer](https://github.com/TASEmulators/BizHawk/blob/bdddf4a58aa1a022afb11dc73294a81a5aa7bbd5/src/BizHawk.Client.Common/savestates/ZipStateSaver.cs), [GFX layout](https://github.com/TASEmulators/BizHawk/blob/bdddf4a58aa1a022afb11dc73294a81a5aa7bbd5/wonderswan/gfx.cpp), [memory layout](https://github.com/TASEmulators/BizHawk/blob/bdddf4a58aa1a022afb11dc73294a81a5aa7bbd5/wonderswan/memory.cpp).
