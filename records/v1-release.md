# GBA Battle Spirit Ver. 1.5 포팅판 v1.0.0

이 버전은 미국판 GBA와의 공통 대전, 포팅판끼리의 확장 대전, 1.5 본편·컬렉션·Digimon Shoot, 네 언어와 선택형 전투 보조를 담는다. 무보조 전체 캠페인, 실물 카트리지·케이블, 공개 환경의 장시간 플레이는 배포 후 검수한다. [패치 적용과 테스트 제보](release-v1-guide.md)

제품 소스가 확정된 커밋은 `7d9b394`이며, 배포용 manifest에 최종 태그 대상 커밋을 기록한다. 미국판 원본에 BPS를 적용해 만든 GBA 파일은 검수에 사용한 롬과 16,777,216바이트 전체가 일치했다.

## 서로 다른 두 게임의 통신

비표시 환경의 mGBA 빌드 9127(`fa977ccbc8`)에서 수정하지 않은 USA와 최종판을 각 코어에 적재하고, 서로 다른 EEPROM으로 시작했다. 각 코어에서 실제 적재된 카트리지 전체, 송수신 버퍼, 플레이어 역할, 득점, 결과 승인과 재대전을 관찰했다. 표의 점수는 코어 1 대 코어 2 순이다.

| 배치 | 실제 역할 | 대표 승패 | 경기 후 확인 |
| --- | --- | --- | --- |
| 코어 1 USA / 코어 2 포팅 | USA 역할 8·side 0, 포팅 역할 0·side 1 | 2–2 무승부, 1–0 USA 승, 0–2 포팅 승 | 양쪽 결과 승인, 선택 화면 복귀, 재대전, 각 저장 파일로 새로 시작 |
| 코어 1 포팅 / 코어 2 USA | 포팅 역할 8·side 0, USA 역할 0·side 1 | 1–1 무승부, 0–5 USA 승, 1–0 포팅 승 | 양쪽 결과 승인, 선택 화면 복귀, 재대전, 각 저장 파일로 새로 시작 |

USA 쪽은 기본 0~6과 원본 세이브에서 해금한 7~11을 고를 수 있다. 포팅판의 호환 대전에서는 원더스완 1.5의 호환 규칙에 따라 0~10과 해금된 임프몬(11)을 고른다. 양쪽이 처리하는 진화는 0~10의 원본 진화이며 임프몬은 원본의 동글몬 접촉 동작을 따른다. 공통 무대 선택표의 실제 순서는 0, 1, 2, 6, 5, 3, 4다. 포팅판 전용 ID 12~14와 추가 무대가 호환 경기의 송신 경로로 들어가지 않는지 확인했다.

v94에서는 호환을 선택해도 포팅 전용 캐릭터가 표시됐고, 1.5 대전을 골라도 USA와 경기에 들어갈 수 있었다. 최종판에서는 호환 선택·표시·확정에 같은 공통 목록을 쓰며, 1.5 대전은 캐릭터 정보를 보내기 전에 양쪽이 확장 통신을 선택했는지 확인한다. 메뉴가 맞지 않으면 B로 타이틀에 돌아가 다시 연결할 수 있다. USA의 응답과 저장 데이터는 원래 게임이 만들었다. 코어마다 재시작 후 읽은 기본 저장 데이터 196바이트와 체크섬을 확인했다. 1인 보조가 켜진 세이브로도 통신 경기에서 실제 피격과 일반 득점을 확인했다. 네 언어에서 버전 선택, 취소와 재진입도 검사했다. 혼합 통신과 언어 검수 보고서의 SHA-256은 `0BDDBDAD3287DFF22141F490090365F664A331A97C1B75085C427EF0B320B6B0`다.

## 포팅판 두 대의 확장 대전

양쪽에서 1.5 대전을 고른 뒤 실제 선택 화면에서 파닥몬(13)과 가트몬(14)을 선택했다. 무승부 후 재대전에서 코어 2가 1–0으로 승리했다. 양쪽 결과 카드의 그림·효과음과 실제 EEPROM의 캐릭터별 대전 횟수·승수, 태그 수량·연승 결과를 확인했다. 두 검증 보고서 SHA-256은 `41B11FB43F13A50F6348EF038FB6291A88F729C17316A6B063C0E79D4DE8F0F8`, `900BD6FA7DAC9649A650F1D38D5AE2DF5FCB71C9A2A5F731811A1402F78C363F`다.

승급 직전 수량을 넣은 별도 시험용 세이브 두 개로 실제 경기를 치른 결과, 승자가 마스터 태그를 획득하고 이름 AAA를 입력했다. 승자 저장 파일로 새 프로세스를 시작해 타이틀과 컬렉션에서 이름과 태그를 확인했다(`7D211479586F29FDA44AA139C954E0B6EFA54780F18643185E5A4CD9E55EDF2A`). 이전 개발판과 정식판 사이의 1.5 확장 대전은 배포 검수 범위 밖이다.

| 대상 | 이번 확인과 재사용한 근거 |
| --- | --- |
| 별도 Digimon Shoot | BizHawk 2.11.1에서 실제 플레이로 얻은 마지막 보스 직후 체크포인트를 이어 컬렉션으로 들어가 최종판으로 7라운드를 이겼다. 클리어 저장 후 타이틀로 복귀했다. 그 저장으로 게임을 새로 켜 다시 들어가 패배한 뒤에도 타이틀 복귀와 저장 보존을 확인했다. |
| 캐릭터·진화 | 15명의 실제 전투 동작을 확인했다. 추가 진화 4종은 동글몬을 만난 뒤의 조작, 진화 해제와 다음 화면까지 확인했다. |
| 본편·엔딩 | D-스피릿 999와 보스 체력 1을 게임 옵션에서 켜고 어려움으로 진행한 v94 기록을 재사용했다. 7·11단계 보스를 각각 한 번 공격해 쓰러뜨린 뒤 엔딩과 타이틀에 도달했다. 최종판에서 싱글플레이 분기와 저장 데이터의 소유 범위를 다시 대조했다. 혼합 대전 6판을 치른 실제 저장으로 게임을 새로 켜 전적 5페이지의 15명을 모두 확인하고, 타이틀 복귀 후 다시 열었다. 추가 무대와 엔딩 보상·해금·태그는 아래 기능별 실행 기록에 정리했다. |
| 네 언어 | 기존 메뉴 52화면과 초상화 60장의 기록을 다시 대조했다. 최종판에서 네 언어로 혼합 대전에 들어가 선택 화면 8장의 실제 초상화를 롬에서 읽은 그림과 비교했다. 한글 이름의 글자 사이는 배경 2픽셀, 한국어 타이틀 크레디트 높이는 영문과 같은 7픽셀이다. 화면과 소리 자체에 별도로 저장할 값은 없다. |
| 오프닝·음향 | 네 번째 오프닝의 두 캐릭터와 타이틀 전환에 쓰이는 데이터를 대조했다. 기존 실측에서 시작 버튼을 누른 뒤 전환까지 원더스완은 1.33825초, GBA는 1.33942초였다. 최종판의 실제 대전에서 추가 효과음 5종의 재생 요청을 확인했다. 진화 음악 4곡의 정지·재개·무대 음악 복귀는 보존된 실행 기록을 대조했다. GBA 음원의 음높이 간격과 배음에는 기종 차이가 남는다. |

## 재현 빌드와 배포 검증

제품 커밋 `7d9b39441f250e75905c91caa4a5a6d8c6ef7029`의 주 빌더와 미국판 GBA·원더스완 1.0·1.5 원본으로 빈 폴더 두 곳에서 처음부터 빌드했다. 별도로 검증된 원작 효과음 추출본 두 세트를 사용했다. 두 빌드 모두 종료 코드 0을 반환했고 각각 생성한 594개 파일의 상대 경로와 SHA-256이 전부 일치했다. 최종 GBA 두 개는 실제 통신·Shoot 검수 후보와 전체 바이트가 일치했다. 전체 파일 비교 보고서 SHA-256은 `EE315717D286F0ED91F4AB415A4A41E3DEBC8EF3EDF6F5F1E89A3D6E0C02AB0A`다.

재현 빌드에서 다시 만든 BPS도 배포용 패치와 전체 바이트가 같았다. Floating IPS 재적용과 독립 BPS 판독 양쪽에서 미국판 원본으로 같은 게임을 복원했다. 릴리스에는 BPS·한영 적용 안내·검수 및 변경 기록·Galmuri OFL·manifest·SHA256SUMS를 첨부한다. 최종 소스 커밋과 각 검수 보고서의 해시는 릴리스에 첨부한 manifest에 있다.
