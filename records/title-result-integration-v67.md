# v67 — 1.5 타이틀 배경과 결과 그림 통합

기준 커밋은 `56a888444fa384a315848bef14e455d081bc6487`(v66)이다. 이 체크포인트는 완성본 포팅이 아니다.

## 구현 범위

- 원본 1.5의 타이틀 배경을 기존 GBA 타이틀에 연결했다. 공유 타일을 덮어쓰지 않고 별도 검증한 공간과 기존 DMA 호출을 사용한다. 추가 메뉴의 상태 전환은 아직 없다.
- 기존 mode8 결과 자원을 네 언어 선택에 연결했다. 영어는 WINS, 일본어·한국어·디지코드는 일본어판 WIN과 DRAW를 사용한다.
- 한국어 마지막 기회!는 원본 픽셀 크기로 제작했다. 사용자의 확대 요청에 따라 디지코드 라스트 찬스!를 기존64×16에서102×16으로 키웠다. 기호 몸체는89×16이며,27개 조각과26개 타일을 사용한다. 일본어 읽기와 두 번 나오는 ス의 동일한 모양을 유지한다.
- 픽셀 제작과 독립 QA를 분리했다. 확대 첫 시안의 붙은 테두리를 고친 v2만 채택했다. 원본 느낌표와 색상을 보존한다.
- 생성 결과는 이전 임시 PNG나 JSON 없이 원본 ROM·추적 중인 기호표·생성 코드에서 다시 만든다.

## 실행과 남은 범위

타이틀 중간 ROM494D는 창 없는 정상 입력으로 타이틀과 캐릭터 선택에 도달했다. 독립 캡처 검사에서408개 타일·504개 맵 셀과 실제 메뉴 감광 팔레트가 일치했다. 명세와 보고서는 `records/title-background-qa.md`에 있다.

최종 A4CB에서 각각 별도의 새 프로세스·저장 경로로 한국어b, 디지코드c, 영어d, 일본어e를 실행했다. 네 경우 모두 정상 버튼 입력으로 옵션 저장→타이틀→전투→WIN 결과에 도달했다. 실제 저장 함수1회, 결과 자원 초기화7회, 결과 그리기 호출88회와 진입120/300프레임 후 화면을 관찰했다. 모두 전체 로드 ROM과 고정 스크립트가 정확히 일치하며, 실제 화면 네 장도 검수했다. **DRAW와 마지막 기회! 이벤트는 이 실행에서 발생하지 않았다.** 그림 자체의 검증과 실제 이벤트 도달을 구분한다.

종합 실행 보고서 `build/result-language-runtime-20261105.json` SHA-256은 `D4903EBFB0B8D78548AA7044CFCB6F305A9435E7D88EA144BAE211EC0860636B`다. 모든 출력 파일 해시와 완료 신호를 재검사했다. 이 실행은 현재 세션 저장 경로를 확인한 것이며 별도 재실행의 저장 재로드 검사는 아니다.

첫 한국어 실행a는 옵션 저장과 타이틀 자원 선택을 확인했지만, 검사기가 Start 전용 프롬프트에 A를 보내 중단했다. 부분 관찰로 보존하며 성공 네 건에 포함하지 않는다. 원본의 입력 비트20/40을 확인해 관찰기만 고쳤고, 강화된 모의 검사는 이전 오류 스크립트를 거부한다. 최종 ROM이나 두 전체 빌드는 바뀌지 않았다.

WIN이 파란색인 장면은 원래 승자 측 팔레트 분기다. 기존08089A24의 비트20 검사와08089A40..50의05000240 대상 복사를 통해 원본08089374 팔레트로 바뀐다. 확대 그림의 색상 손상으로 간주해 임의 수정하지 않았다. 네 실행을 마친 뒤 소유한 에뮬레이터 프로세스가 남지 않은 것도 확인했다.

Shoot 외부 진입과 컨트롤러는 여전히 닫혀 있다. 별도 원본 관찰j는900초 제한으로 중단했으며90,000프레임 완료가 아니다. 저장 소비자·종료 IRQ·카메라 수명과 실제 좌표/플래그 소유권이 남아 있다. 조건부 X 범위의 독립 계산을 전체 Y·장면 수명 증명으로 확대하지 않는다. E5 실행 주소 문제의 원인도 미해결이다.

제공 WSC 세이브는 사용하지 않았다. 생성 ROM·캡처·메모리 덤프는 로컬에만 보관한다. 전체 콘텐츠·추가 메뉴·전체 번역·최종 하드웨어 QA는 미완료다.
