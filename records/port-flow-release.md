## 재검증

`tools/verify_port_flow_release.py`는 허용된 후보 전체 해시를 확인하고 실행 당시 동결한 Lua·ROM·로그를 다시 읽는다. ID별 전투·진화·복귀 프레임, Shoot의 실제 7라운드, 통신 저장과 15인 전적, 보조 캠페인 종료 및 냉간 재시작을 검사한다. 과거 검수에서 실제 실행한 롬과 후보의 엔딩·해금 7개 범위, 태그 열람/저장 85개, VS 표시/전적 저장 15개 범위도 각각 바이트 단위로 대조한다. 선택 화면이나 강제 진화 진단을 실제 전투 근거로 사용하지 않았다.

```text
python tools/verify_port_flow_release.py --candidate build/mixed-compat-preview-a/component.gba --output build/flow-release-ledger-a/report.json
```

집계 파일 SHA-256은 `B11340FBAB50AF9525A1BDE825C85A2D346D3D4223E188B83C56646E53DEABF1`이다. 15인 가운데 ID 2·3·6·7·11·14는 이번 혼합 호환 후보, 나머지는 v94에서 실제로 실행했다. 일반 1인 선택·전투 계통은 두 빌드에서 같은 동작을 따른다. 집계 파일은 사용한 빌드를 각 실행의 ROM 해시로 구별한다. 플레이에서 획득한 체크포인트와 ROM·세이브·캡처는 로컬 `build/flow-release-*`에 보관한다.
