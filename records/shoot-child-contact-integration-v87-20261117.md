# v87 — Shoot 접촉 후 잘못된 애니메이션 진입 수정

후보 ROM은 `5284435AE1BA291699331F5A899358D254844E7EA4784A60D250DCEF2A07CECC`다.
최종판이 아니며 추가 모드23은 아직 주 빌드에 연결하지 않았다.

## 실제 원인과 수정

v86 전체 플레이는 11경기와 Shoot 조작 시작89405까지 진행했지만,
90753에 게임 모드가7에서77로 바뀌었다. 별도 읽기 전용 재현에서 그래픽
출력의477번째 스프라이트가 모드 저장 주소03002310까지 넘친 것을 확인했다.
이어 더 이른 시점을 관찰하여89627의 충돌 분기가 Shoot 공격 오브젝트를
소매판 콜백083723E0으로 바꾸고,89628에 없는 이벤트5를 요청함을 확인했다.
후속 이벤트6은 팔레트03E00360을 그림 개수로 읽었다. 당시 stage11 체력
보조 쓰기는0회였으며, 입력은 Right 두 프레임 후 해제였다.

원본760E4B..760E95에는 stage11일 때4090:966A로 가는 별도 분기가 있다.
이를 복원하고966A/96E6/973E와9797까지의 후속 처리를 연결했다. 원본처럼
부모의 부모에 재사용 대기 값을 기록하고, 대상의 상태·효과3·소리·이벤트1,
16비트 타이머·이벤트2·정리·추적 좌표를 원래 순서로 처리한다.
렌더러 개수 제한이나 애니메이션 번호 대체로 증상을 숨기지 않는다.

새 코드는D8C800..D8CA68에 배치했다. 예약은D8C800..D8CE00이고, 기존
분기 한 곳을 포함하여620바이트를 선언하고607바이트를 변경했다. RAM은
추가하지 않았다. 처음 검토한D8B800 예약은 보수적인 인바운드 검사에 걸려
사용하지 않았으며, 검사 예외를 추가하지 않고 배치를 옮겼다.

## 독립 검증

순수 콜백 ARM 검수 `D6958EA2`는 비stage11의 상태 보존, 부모 링크,
타이머0000→FFFF와8000→7FFF, 대상 상태와 이벤트·정리 순서를 확인했다.
전체 이미지·실제 native 이벤트/갱신/오디오 소비자 검수 `74462AE3`는
전체 역변환, 예약 소유권, 인바운드0건, 유효한 그림0/1과 종료를 확인했다.
시각 효과의 생성·수명·그림은 별도 원본 대응 검수 `05CF69F9`를 사용했다.

창 없는 실제 수정 후 실행은 원래 프로세스 종료0이다.89628에 새966A와
효과3이 실행되고,90753에는 이벤트2,90768에는 오브젝트 정리까지 도달했다.
마지막90769에서 모드는7, 표시 커서는35, 전투 상태는0006이었다.
독립 실제 검수는 `DFD2B957`이다. 관찰기에 남은 `first_outside=false`라는
문자열은 이 검사의 전체 프레임 OAM 검사 결과가 아니므로 그렇게 주장하지 않는다.

이 재현은 이번 전체 플레이에서 만든 정상 진입 체크포인트의 복사본을
사용했다. 복원한 다섯 메모리 영역, CPU 영역·native 확장·관리 프레임 정보는
확인했지만 전체 Core에는15바이트 차이가 남았다. 전체 Core 동일성을
주장하지 않으며 차이는 각 실행 매니페스트에 그대로 보존했다.

## 통합 상태

주 빌드는 두 독립 검수를 필수 단계로 호출한다. 원본부터 시작한 두 새 빌드는
각각 원래 프로세스 종료0이다. 독립 전체 산출물 검수 `79C9465A`에서356개
파일·135개 매니페스트 항목 일치와 이전352개 산출물 보존을 확인했다.

새 전체 플레이는11경기와89405 조작 시작 이후95279까지 모드7을 유지했다.
자동 입력이 공격 조건에 도달하지 못한 채 P1체력0/P2체력37이 되어
`failure:wholeplay-live-aim-owner`로 원래 프로세스가 종료1이었다.
stage11 체력 쓰기는0회다. 이 결과는 전체 완주가 아니라 정상 모드를 유지한
패배이며, 입력 전략과 공격 조건의 별도 검수가 필요하다. 전체 실행 기록은
`build/bizhawk-wholeplay-v87-20261117-a`다.

추가 모드23의 실제 메뉴·진입·종료, 전체 네 언어 콘텐츠, 최종 저장·리셋과
안정성 검증은 여전히 남아 있다. 이번 성공은 Shoot 공격 오브젝트 접촉 수명에
한정하며 전체 게임 완주로 확대하지 않는다.
