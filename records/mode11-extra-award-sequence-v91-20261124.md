# Extra Guilmon's post-clear animation and cold unlock

A successful SPECIAL tag earned during name entry produced no unlock until the following no-continue campaign. On the winning path, the permitted test aids wrote the player's D-Spirit score to 999 on 38 occasions and set the active stage 7 and stage 11 boss to one HP once each. At stage 11 the player landed the final attack at frame 189229. The first attempted route had lost this fight. Replaying the authentic stage 11 checkpoint with different controller inputs produced the winning path. No tag, roster, stage, player HP or ending registers were modified. The game set pending 10 then 30 (hex) itself and committed both at 202220, queuing Impmon and Extra Guilmon in slots 0 and 1.

The image 78447E05 reached the congratulations scene but stopped before returning to the title. The ID 12 actor at native 080C0A24 looked up the animation by fighter ID minus seven. The five USA pointers cover IDs 7–11. For ID 12 the next four bytes held the first two animation halfwords, giving FFFF005C as a sequence pointer. The ID 11 actor finished, leaving the count at one even with ordinary button input. This was reproduced from the same naturally earned checkpoint.

In the original WonderSwan ROM C415F227, the six entries at 77ADEF index offset 0ECF for ID 12. Segment 779F50 plus this offset gives 77AE1F, the sequence 006C followed by FFFF. The corrected image copies the five existing native pointers and adds a sixth pointer to this four-byte source sequence. It redirects only the native selector literal and adds 28 bytes in an independently allocated range. The fixed isolated ROM is `543F19927D5A21FA80C7EF70D50F571768E8F9C67F75847A13BAAFEEEA7ADA23`, its owner manifest is `9A07B5D2F5B0748EAAE4D7DACBA4525D6FCA4562F84EDC1EA7E3CDE833D7A195`.

With the same award checkpoint, both native actors finished and released the queue. The game accepted the name at 202912, followed the FF path, entered mode 20 and returned to the title. A new process booted from the earned physical EEPROM only. The normal character selector loaded both Impmon and Extra Guilmon. Their hardware VRAM name/portrait-header blocks match the corresponding 768-byte ROM ranges. This run used no supplied save. Both permanent flags survived, pending was zero, and the SPECIAL counter remained one. The physical save SHA-256 was `AE15A17E9B0B4C66EC85A19AA390069048A0D9B9B973CDC05FFACAE220995E5D`.
