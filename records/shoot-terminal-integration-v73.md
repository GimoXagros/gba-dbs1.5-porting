# v73 — Shoot 종료 IRQ와 보스 격파 연결

2026-11-09. v72의 검증된 코드 위에 두 연결을 통합한 개발 체크포인트다.
전체 포팅 완료나 Shoot 외부 진입 완료를 뜻하지 않는다.

- 화면 준비 목록을 복사한 뒤, 정지한 기본 ID0 플레이어와 종료된 보스·보조 객체,
  현재 배경 행·빈 타일·화면 형식을 확인한다. 조건이 맞으면 원본의 8단계 종료 IRQ를
  사용한다. GBA의 160줄 전체를 검사하며, 조건이 맞지 않으면 기존 목록을 유지한다.
- 화면 처리 자체는 하드웨어 1번째 줄에 실행된다. 긴 검사를 그 안에 넣지 않았다.
  태스크 우선순위의 실제 저장값 FFFFF000과 종료 후 mode8 잔존 콜백도 검사한다.
  원본의 중단 시점 DI를 상수나 임의의 GBA 레지스터로 대체하지 않는다.
- stage11 보스의 치명타는 기존 상주 어댑터로 연결한다. 보스와 연결된 보조 객체가
  각각 원본에 대응하는 종료 콜백을 받는다. HP 계산과 공통 후속 처리는 그대로다.
  이 연결은 4바이트이며 새 함수 본문·RAM·태스크를 만들지 않는다.

원본 세 개와 고정 폰트에서 새로 만든 A/B 빌드가 모두 정상 종료했다.
295개 파일의 전체 경로·해시와 각 115개 매니페스트 항목이 일치한다.
새 변경은 5곳, 선언 1,580바이트·실제 변경 1,554바이트이며 역변환하면 v72 전체 ROM과 같다.
기존 자료는 최종 ROM·최종 구성 매니페스트·전체 빌드 매니페스트 외에 변하지 않았다.

정확한 v73 ROM으로 한국어 설정 저장→타이틀→일반 전투→WIN→300프레임 후까지 창 없이
검증했다. 화면 8개, EWRAM·VRAM·팔레트·OAM·표시 레지스터와 실행 기록은 v72와 같다.
관찰한 프레임 차이는 0이다. IWRAM의 스택 7–8바이트 차이는 별도 기록했다.
이는 일반 전투 회귀 검증이며 실제 GBA Shoot 진입이나 모든 RAM의 동일성을 주장하지 않는다.

Shoot 외부 진입, 움직이는 낮은 Y 진입 계열, 비치명타 연결, 전체 콘텐츠·번역,
E5 최초 잘못된 쓰기와 최종 QA는 남아 있다. 완성본 ROM/BPS로 배포하지 않는다.
