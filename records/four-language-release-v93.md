# 네 언어 검수판 v93

타이틀의 ‘혼고 아키요시·도에이 애니메이션’에 7픽셀 한글 글꼴을 적용했다. 기존 11픽셀 표기보다 4픽셀 낮아졌고, 글줄 너비는 137픽셀에서 121픽셀이 됐다. 왼쪽 저작권 기호와 아래 BANDAI 연도 표기는 원래 자리에 있다. 실기 해상도 240×160에서 흰 글자의 높이는 영어 7픽셀, 일본어 8픽셀, 한국어 7픽셀이다. [자형과 원본 대조 기록](four-language-menu-review-20261124.md).

## 엔딩과 통신 대전

어려움 난이도에서 2,310점으로 마스터 태그를 얻고 BCD를 입력했다. 게임을 완전히 종료한 뒤 저장 메모리로 새로 시작해 태그와 이름을 확인했다. 점수 집계음이 멈출 때 다른 효과음이 같은 채널에서 계속 재생되는 경우도 확인했다. [캠페인 엔딩 검증](mode11-earned-tag-score-20261124.md) · [점수와 태그 소리](tag-result-audio-v92-20261124.md).

두 GBA 에뮬레이터를 케이블로 연결해 태그를 주고받았다. 승리한 쪽에서 마스터로 승급하고 이름 AAA를 입력했다. 새로 시작한 게임의 타이틀과 컬렉션에 승급 결과가 남았다. `build/cold-link-reward-special-celebration-20261124-b/verified.json`에서 저장 후 타이틀 표시와 태그 열람을 확인했다.
