# 타이틀과 캐릭터 선택 검수

영문 메인 메뉴의 OPTIONS는 미국판 버튼 그림에서 마지막 S의 네 열만 살아 있었다. 같은 글꼴에서 여섯 열이 모두 있는 S를 가져왔다. 버전 대전 두 번째 버튼은 VS VER B•S로 바꾸고, B와 S도 기존 버튼에서 옮겼다. 실제 메인 메뉴의 스프라이트 110개와 대전 메뉴의 44개를 게임 화면과 대조했다. 수정 전후 검수 결과는 `5C941BBD`다.

원더스완 1.5의 영문 타이틀 그림에 AKIYOSHI HONGO · TOEI ANIMATION이 남아 있다. 영문판에서는 저작권 기호부터 마지막 N까지 원본의 위치와 자간을 복원했다. 마지막 칸은 영어에서만 별도 팔레트를 사용한다. 한국어는 ‘혼고 아키요시·도에이 애니메이션’으로 썼다. 디지코드는 일본어 독음 ‘ほんごうあきよし・とうえいアニメーション’을 따르고 작은 ョ를 표의 ヨ에 대응시켰다. 일본어는 원본 그대로다. 네 언어 모두 아래 줄의 © BANDAI 2002가 표시된다.

검수 롬은 `97250CFD0BEF5CFD3D5531D71397F6A4A6AA7EC8021079B23BCC4063C10B18D5`다. 설정에서 언어를 바꾸고 직접 메뉴를 따라가며 태그 획득 전후를 창 없이 촬영했다. 언어별로 타이틀의 실제 408개 타일과 저작권 두 줄을 포함한 3,840픽셀을 검사했다. 이전 화면을 복사해 붙인 언어 칸은 없다. 두 화면 보고서의 해시는 `6F721CE0`, `E34D0EEC`다. 일반 타이틀과 복귀 장면의 언어, 플래그, 메모리 경계를 검사한 56개 경우도 통과했다.

- 메뉴 검수표는 `build/menu-review-four-languages-20261124/menus-revised.png`다. 실제 화면 52장을 원본의 두 배 크기로 배치했다.
- 초상화 검수표는 같은 폴더의 `all-portraits.png`다. 15개 슬롯을 ID 순서대로 나열하고, 롬에 설치된 이름판 60개와 그 아래의 96×112픽셀 그림을 대조했다. 아구몬 세 슬롯과 길몬 두 슬롯을 구분했다. 이 표는 롬 데이터에서 원본 픽셀을 추출해 만들었다.
- 영문 버튼만 비교하려면 `build/english-menu-lettering-qa-20261124/buttons-before-after-4x.png`를 연다.

### 검수용 롬 적용

로컬 폴더 `build/title-credits-v91-r2-20261124`에 실행용 `component.gba`와 `menu-review.bps`가 있다. 패치로 직접 만들 때는 Floating IPS의 **Apply Patch**에서 BPS 파일, 미국판 원본, 새 출력 파일을 차례로 선택한다. 미국판 원본 SHA-256은 `996DE33330AC729D10D761D1901E7A335191C9503B0470569E8F294ACF6618ED`다. 검수용 BPS는 673,811바이트이며 SHA-256은 `E17A7F0C66E35FAD786A64116A912A57D8FA82EBCA47AD96A5850DE8C75F2142`다. 이 패치를 원본에 적용한 뒤 검수 롬과 16 MiB 전체가 일치하는지 확인했다.
