# 엔딩 점수와 마스터 태그 검증 · 2026년 11월 24일

원더스완판은 클리어 점수를 계산한 뒤 점수판을 710프레임 동안 보여 준다. 일반 등급을 받은 원본 플레이에서는 태그 획득 화면이 399프레임 이어졌다. 이 순서를 GBA판의 엔딩에 연결했다.

## 실제 플레이

통합 빌드 `249FB4C3`에서 11단계 클리어 직전의 기록을 이어 했다. 어려움 난이도에서 2,310점을 얻자 점수판에는 세 자리 릴의 상한인 999와 총점 2310이 함께 나왔다. 마스터 태그가 나타난 뒤 캐릭터가 뛰어 들어왔고, 색종이가 떨어지는 동안 이름 입력 화면으로 넘어갔다.

방향키와 A 버튼으로 BCD를 입력했다. 타이틀로 돌아온 프레임은 227240이었다. 게임을 종료하고 저장 메모리만 복사해 새로 시작했다. 컬렉션의 마스터 태그에 BCD가 남아 있었고, B 버튼을 누르자 3363프레임에 타이틀 배경으로 돌아왔다. 이 두 번의 실행에서는 게임 메모리를 고치거나 제공받은 세이브를 쓰지 않았다. 출발점은 앞서 보조를 사용해 진행한 캠페인의 체크포인트다.

## 점수판 소리

점수판 진입 후 61프레임에 음악이 시작되고 92프레임에 릴 소리가 더해졌다. 105프레임과 250프레임에는 둘 다 재생 중이었다. 318프레임에 릴을 멈췄을 때 점수판 음악은 이미 자연스럽게 끝난 상태였다. 같은 재생기를 다른 효과음이 쓰는 별도 시험에서는 릴 정지 요청 502회 뒤에도 그 효과음이 계속 들렸다.

## 확인 범위

원본에서 직접 기록한 획득 화면은 일반 태그이고, GBA의 실제 클리어로 확인한 화면은 마스터 태그다. 별도 ARM 검사에서는 태그 11종의 팔레트와 타일 배치, 캐릭터 15종의 양쪽 선택과 색상, 저장 실패 시 복귀를 확인했다. 통신 대전의 마스터 태그 연출과 게임 전체 플레이는 별도로 검증한다.
