# 시작 안내와 캐릭터 이름 검수

한국어를 선택하고 캐릭터 선택 화면에 처음 들어가면 길몬 초상화에 영문 이름 GUILMON이 남았다. 첫 화면에서는 게임이 길몬 그림을 직접 복사했고, 언어별 이름을 그리는 코드는 커서를 옮길 때만 실행됐다. 첫 화면에서도 길몬 그림을 복사한 직후 선택한 언어의 이름을 덧그리도록 수정했다.

수정한 롬 F6105339로 창을 띄우지 않고 언어마다 새 게임을 시작했다. 설정에서 언어를 저장한 뒤 타이틀로 돌아가 시작 안내와 메뉴를 확인했다. 한국어와 디지코드 시작 안내는 영어·일본어와 같은 노랑·주황 글씨에 어두운 테두리를 쓴다. 디지코드 메뉴 다섯 줄은 각각 너비 88픽셀인 버튼 안에 들어갔다.

캐릭터 선택 화면에서는 네 언어 모두 첫 초상화와 커서를 한 번 옮긴 다음 초상화를 확인했다. 한국어 화면에는 길몬과 테리어몬이 차례로 나왔고 음절 사이에는 빈칸이 2픽셀씩 있었다. 네 언어의 이름판 8개에서 각각 1,536픽셀을 화면 캡처와 비디오 메모리와 대조했다. 모두 일치했다.

실제 조작으로 확인한 캐릭터는 길몬과 테리어몬이다. 나머지 13명을 포함한 전체 15명의 이름은 네 언어의 그림과 롬의 표시 코드를 대조해 검증했다. 전체 포팅의 완료 여부는 이번 화면 검수 범위에 포함하지 않았다.
