# v1.0.0 독립 검수

미국판 GBA 원본 `996DE333…6618ED`, 원더스완 1.5 원본 `C415F227…D76FD7`, v94 `EF8BBC67…7B75BA`와 최종 후보 `AA6BB1EB93027464F842D6EB0CC69A68959F26B38460FAF1B0C63BDD5FFA4BB1`을 사용했다. 새 제작 코드와 별도로 원본 코드·설치된 바이트·실제 프레임을 검사했다. 실행 기록과 캡처는 로컬 `build/`에 보존한다.

| 포팅판 ↔ 포팅판 | 최종판 두 코어가 확장 캐릭터로 경기한 뒤 양쪽에서 태그 카드 증감과 선택 복귀를 기록했다. 승급 시험에서 실제 저장 후 새로 시작했을 때 12승·10단계와 이름 AAA가 유지됐다. 준비한 두 개의 유효 세이브와 실제 경기 후 저장을 구분한다. |

| 원작 열차 | 실제 Stage 8에서 초기화 1회, 무대 갱신 9,376회, 검사한 흔들림 본체 진입 0회였다. 이 관찰 범위에서 필수 동작 누락을 뒷받침하는 실행 증거가 없었다. 조건부 경로의 도달 가능성은 열어 둔다. |

픽셀·음향 검사는 `python tools/verify_independent_release_media.py --build build --image <final.gba> --report <report.json>`으로 수행했다. 보고서 SHA-256은 `749ACBA49435817EAE2BD2CE65A97AA1EBF01E434E502A2F08E408457F51EA39`다. 이전 에뮬레이터 캡처를 재사용한 항목과 최종판에서 새로 발생시킨 행동을 분리해 기록했다. 에뮬레이터는 비표시 환경에서 실행했다.

## 패치 판독

BPS 705,426바이트의 SHA-256은 `263BFDC41B9CA2A63AD831AFDFCD61895BBD50CABB118C33AF8C4ED6682D303F`다. 배포기가 사용한 Floating IPS와 별도로 BPS를 해석해 원본·결과·패치 CRC32 세 개를 검증했다. SourceRead 251회, TargetRead 34,298회, SourceCopy 16,059회, TargetCopy 61,977회를 적용한 결과가 실제 검수 후보 16,777,216바이트와 전부 일치했다.

## 독립 판정

제품 소스 `7d9b39441f250e75905c91caa4a5a6d8c6ef7029`에서 빈 폴더 A·B로 시작한 두 주 빌드가 모두 종료 코드 0으로 끝났다. 전체 594개 상대 경로·파일 해시가 일치한 비교 보고서를 확인하고, 양쪽 폴더의 실제 파일 목록을 독립적으로 대조했다. 두 최종 ROM과 실전 검수 ROM의 전체 16,777,216바이트, 양쪽 ARM 검수 보고서와 OFL 원문도 다시 읽어 일치 여부를 확인했다. 재현 보고서 SHA-256은 `EE315717D286F0ED91F4AB415A4A41E3DEBC8EF3EDF6F5F1E89A3D6E0C02AB0A`다.

최종 ROM과 BPS, 독립 재현 빌드는 이번 승인 범위의 제품 검수를 통과했다. 위 실제 플레이 경로에서 진행 중단, 저장 손상 또는 지원 범위 밖 항목의 혼합 전송이 재현되지 않았다. 배포 파일은 BPS, 한·영 적용 안내, 릴리스 노트, Galmuri OFL, manifest, SHA256SUMS의 여섯 항목으로 한정한다. 태그 대상과 게시 파일 재다운로드 검증은 릴리스 책임자가 마무리한다.

무보조 전체 캠페인, 물리 GBA·링크 케이블, 공개 환경의 장시간 검수는 v1.0 배포 후 범위다.
