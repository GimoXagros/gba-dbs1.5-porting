# V81 75BD 실제 캠페인과 화면 독립 검수

75BD 후보는 첫 Train 경기와 다음 경기를 넘어 세 번째 Waterfall 경기까지 진입했다. 원래 호스트는 120,000프레임을 모두 진행한 뒤 `bounded-no-activation`을 기록했다. 완료 매니페스트는 정상적으로 닫혔으며, 호스트 종료 코드 1은 캠페인 성공을 요구한 마지막 검사에서 나왔다. 호스트 중단 요청과 시간 제한 만료는 없었다.

| 진행 | 실제 스테이지 | 실제 CPU ID | 생산자 코어 | 활성 배우 코어 |
|---:|---:|---:|---:|---:|
| 0 | 8 (Train) | 13 | 3522 | 3932 |
| 1 | 1 | 1 | 11639 | 12038 |
| 2 | 9 (Waterfall) | 14 | 19745 | 20144 |

RNG 행 2와 기본 P1 ID0, 난이도 2가 세 경기에서 유지됐다. 3개 생산자 반환의 실제 ARM 레지스터와 RAM, 3개 활성 경기의 배우 슬롯·역할·상호 연결·컨트롤러 콜백을 대조했다. 진행 3은 관찰되지 않았다. 따라서 진행 9/10 HUD, 보스, Shoot 전환은 이 실행에서 확인되지 않았다.

## Waterfall 종료 경계

유효한 게임 충돌 생산자와 쓰기 기록은 코어 20164에서 끝났다. 에뮬레이터는 코어 120001까지 프레임 경계를 반환했다. 마지막 RAM은 모드 7, 진행 2, 스테이지 9, 타이머 7177, 일시정지 0, 종료 플래그 0을 보존했다. P1과 CPU는 각각 체력 8이었고, 점수는 999대 0이었다. 저장된 입력·경기 태스크에는 여전히 활성 헤더와 콜백 `08374FF4`·`083735BC`가 남았다.

마지막 CPU는 `CPSR=4000009B`의 ARM undefined 모드였고 `SPSR=40000010`, `R15=00000394`, 예외 복귀 주소 `R14=E3A00004`를 기록했다. 75BD의 디스패치 `080C65D4..080C65F0`와 실제 레지스터가 일치한다. `03003D50`의 플래그 WORD `000F`에서 인덱스 15가 만들어지고, 테이블 주소 `080C65F4 + 15×4 = 080C6630`에서 명령어 WORD `E3A00000`이 대상 주소로 읽혔다. 실제 `R2=R5=0000000F`, `R8=080C65F4`, `R9=E3A00000`이다. 관찰된 마지막 충돌과 종료 레지스터는 이 잘못된 분기까지 위치를 좁힌다. 플래그 `000F`를 처음 만든 명령과 해당 프레임 내 순서는 별도 관찰이 필요하다.

## 화면과 카메라

- Train 코어 3932에서 카메라와 BG0는 `(0,116)`이다. P1 `(64,68)`은 보였고 CPU13 `(392,76)`은 오른쪽 화면 밖이었다. P1 OAM 12개에서 복원한 503개 불투명 스프라이트 픽셀이 캡처와 모두 같다.
- 두 번째 경기 코어 12038에서 카메라/BG0는 `(152,44)`, P1 `(112,68)`, CPU1 `(32,68)`이며 두 배우가 실제 화면에 보였다. OAM 26개가 활성이다. 코어 12095의 동작 화면에서 카메라가 `(124,44)`로 움직였고 CPU의 직전 월드 위치가 실제 화면 좌표 `(98,68)`로 투영됐다.
- Waterfall 코어 20144에서 카메라/BG0는 `(0,0)`이고 P1 `(80,48)`, CPU14 `(112,416)`은 실제 월드 좌표에서 정확히 투영된다. P1의 12개 OAM 파트는 화면 안이며 OBJ 우선순위 3이다. 카메라로 계산한 503개 P1 스프라이트 픽셀 어디에도 해당 OBJ 색이 표시되지 않았다. BG0 우선순위 2가 앞에 있고 해당 503개 좌표가 모두 불투명하다. 별도 원본 비교가 동일한 폭포 앞가림을 확인했다. [원본 폭포 전경 검수](waterfall-foreground-source-parity-20261117.md)
- 마지막 120001 화면에도 Waterfall과 `01:59`, 점수 999가 남았다. OAM은 15개였다. P1은 같은 `(80,48)`이었고 CPU14는 여전히 시야 아래 `(112,370)`였다. 이 증거는 두 시점의 화면을 설명하며 경기 전체 또는 이후 스테이지의 카메라 동등성을 입증하지 않는다.

## 실행 파일과 승인 범위

매니페스트 `18F2BA67`의 81개 파일, 9개 PNG와 각 6개 메모리 영역, 최종 RAM과 화면을 재검수했다. 전체 16 MiB 적재 ROM, 실행용 복사본과 원본 후보는 SHA-256 `75BD7C17`로 동일하다. 실행 호스트 `18DDDFCF`, BizHawk 실행 파일과 Lua 7개 핀이 모두 일치한다. 자동 저장·불러오기와 배경 물리 입력을 비활성화했다. 사용자 제공 세이브를 불러오지 않았으며, 종료 시 생성된 SaveRAM은 별도 격리 폴더에 있다.

승인된 쓰기는 P1 `+66`의 점수 WORD 999 여섯 건이었다. 스테이지 8에서 2건, 스테이지 1에서 3건, 스테이지 9에서 1건이다. 각 쓰기의 두 바이트와 주소, 직후 값, 이웃 WORD와 P1 체력 보존 증거를 대조했다. 보스 HP 쓰기와 스테이지 11 쓰기는 0건이다.
