# 3FE5 정렬 AI와 Iraira 실제 캠페인 검수

3FE5의 비공개 실행은 11개 경기를 마치고 코어 89405에서 건강한 Shoot에 진입했다. 원래 실행기는 종료 코드 0과 `campaign-eleven-stages-and-healthy-shoot-activation`을 남겼다. 완료 매니페스트 `89D1EBAC`의 304개 파일, 41개 캡처, 런처 `2E68861A`, 코어 전체 16 MiB ROM과 Lua 10개 핀을 확인했다. 사용자 제공 세이브는 사용하지 않았고 격리 데이터 경로에도 생성 세이브 파일이 없었다.

RNG 행 2의 실제 스테이지 순서는 `8,1,9,6,10,3,2,4,5,0,7`, 적 CPU 순서는 `13,1,14,3,11,5,2,6,4,0,15`였다. 실제 생산자 반환과 활성 배우를 전부 확인했다. 진행 9 `BATTLE 10`과 진행 10 `FINAL BATTLE`은 캡처 화면 및 실제 VRAM 타일맵 값이 모두 일치했다. 점수 WORD 999는 31회, 스테이지 7 보스 HP WORD 1은 1회였고 스테이지 11 쓰기는 없었다. 코어 87425의 실제 P1 공격이 HP를 1→0으로 바꿨으며, P1의 HP 8은 저장·복원되어 최종 Shoot에 남았다. 건강한 진입과 보스 체크포인트의 전체 저장 메모리 및 RGB 프레임버퍼를 대조했다. Shoot 클리어는 이 실행의 종료 조건보다 뒤에 있다.

## Waterfall 정렬 AI

CPU14는 정규화 행 9를 유지했다. 코어 19961에서 18바이트 행 간격으로 짝수 주소 `08D8ABA2`를 읽었고 첫 WORD `02E4`가 `03004D8A`에 실제로 복사됐다. 캡처된 `03004D88`에서 15개 필드를 역으로 이어 붙인 17바이트는 원본 기반 행과 정확히 같다. 코어 20199의 실제 액션 복사는 뱅크 `0D80`, 번호 `00CC`, 레코드 `08D8A658`에서 시작했다. 셀렉터 `0008`이 기존 분기표 안의 `080C6630`을 골랐다. 이후 실제 전투를 끝내고 스테이지 6으로 넘어갔다.

## Iraira 화면, 소유자, 시계

진행 4의 첫 활성 화면은 코어 36356이다. 올바른 배경 파이프·기어·플랫폼과 양쪽 배우, `01:59` HUD가 보였다. 화면이 깨졌던 DEEE의 같은 경계는 이 검사에서 거부됐다. 실제 BG0 소유자 `03002388`은 F800과 자원 25, BG1 소유자 `03002338`은 F000과 자원 26을 가리켰다. 원본 기반 BG0 맵의 18개 전체 행 1,008바이트와 BG1 맵의 행 안에 유지된 연속 742바이트를 각각 확인했다. VRAM 타일 495개, 31,680개 픽셀 인덱스가 원본 기반 설치 데이터와 같다. 애니메이션이 덮는 위치를 제외한 초기 팔레트 146바이트도 일치했다. [원본 에셋과 변환 독립 검수](iraira-render-consumers-independent-20261117.md)

실제 `08D8AF8C` 초기화 쓰기는 코어 36173의 위상값 `0000`을 남겼다. 디스플레이 콜백의 `086283AC`는 `0000→0002`와 `0002→0000`을 각각 실제로 썼다. 타이머의 실제 저장 직후 코어 36355–36475의 121개 연속 관찰값은 7199에서 7079로 감소했다. 이 관찰 지점은 화면 전환이나 플레이어 상태를 수정하지 않는다.

팔레트 애니메이션은 한 프레임에서 현재 카운터와 다르게 보였다. 첫 활성 경계의 카운터는 `(5,1,2,3,0)`였고, 원본 기반 투영표 38개 색 중 현재 카운터와 같은 색은 7개였다. `05000082`와 `050000C2`는 현재 카운터의 위상 3 대신 정확한 위상 0이었다. `05000042`의 11개 색은 비교한 단일 행과 맞지 않았다. 배경색 소유자 `03002654`는 타이머 관찰 전 구간에 `0000`이었지만 같은 첫 활성 경계에서 실제 PALRAM 색 0은 `033D`였다. 다음 결과 전환에서는 PALRAM 색 0이 `0000`이었다. 이 실행은 투영기 호출이나 실제 PALRAM 쓰기를 관찰하지 않아 시점 차이와 원래 쓰기 경로를 구별할 수 없다. 올바른 배경 에셋과 경기 진행은 확인됐고, 팔레트 애니메이션의 프레임별 동등성은 이 캡처에서 확인되지 않았다.
